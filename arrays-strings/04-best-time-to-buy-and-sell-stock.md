\## Problem: Best Time to Buy and Sell Stock (Easy)



\*\*Link:\*\* https://leetcode.com/problems/best-time-to-buy-and-sell-stock/



\### Approach



I kept track of the minimum price seen so far while scanning the array. For each price, I calculated the possible profit by selling on that day and updated the maximum profit if it was larger.



\### Complexity



\- Time: O(n)

\- Space: O(1)



\### Notes



Test Case 1:

prices = {7, 1, 5, 3, 6, 4}

Expected = 5



Test Case 2:

prices = {7, 6, 4, 3, 1}

Expected = 0
